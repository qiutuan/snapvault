# ADR-0004: 图层标注设计 — JSON 图层 + 导出时栅格化

- 状态：已采纳

## 背景
硬性约束：**图片永不修改原图**；标注可编辑、可删除单个图元、可撤销重做 ≥20 步。

## 决策
1. 标注模型 `AnnotationModel`：`width/height + elements[]`，每个图元独立 id/type/参数，
   序列化为版本化 JSON（`version:1`），持久化到 `annotations` 表；
2. 图元类型：pen/arrow/rect/ellipse/text/mosaic/blur；
3. 编辑走"快照 + 撤销/重做双栈"，栈深上限 20（`MAX_UNDO=20`），测试断言压满栈后旧快照被丢弃；
4. 导出（annotated 模式）时才用 PIL 在**内存**中栅格化叠加，另存新文件；
   原图文件字节级不变（测试断言 `read_bytes` 相等）。

## 理由
- 图层化保证可编辑性（撤销/重做/删单元素天然成立）；原图只读满足隐私与可追溯。
- 打码强度 `strength`（0~1）控制马赛克块大小 / 高斯模糊半径，可调。

## 后果
- 标注渲染依赖中文字体（`fonts/NotoSansSC-Regular.otf` 已随仓库分发，测试与导出用）。
- 栅格化是内存操作，超大图导出时占用内存 = 原图 + 覆盖层（可接受）。
