# RapidOCR 离线模型（随包分发）

来源：rapidocr_onnxruntime 1.3.x 内置模型（Apache-2.0 / PP-OCRv4, CC BY-NC-SA? 见 PaddleOCR 许可——实际为 Apache-2.0 开源模型）。

- ch_PP-OCRv4_det_infer.onnx   — 文本检测（Det）
- ch_PP-OCRv4_rec_infer.onnx   — 文本识别（Rec）
- ch_ppocr_mobile_v2.0_cls_infer.onnx — 方向分类（Cls）

运行时零网络：OCR 完全在本地 ONNX Runtime 推理。
